🚀 Szybki start

Najszybsza droga do działającego systemu ticketów — wszystko przez przewodnik:

Wskazówka: zamiast kanału forum możesz użyć kategorii kanałów — [p]settickets categoryopen main <kategoria> i opcjonalnie categoryclosed. Role pingowania: [p]settickets pingroles main <role...>.

Przykład pełnej konfiguracji:

[p]settickets enabled main true [p]settickets supportroles main @Support @Moderacja [p]settickets pingroles main @Moderacja [p]settickets categoryopen main "🎫 Otwarte" [p]settickets categoryclosed main "📦 Zamknięte" [p]settickets logschannel main #ticket-logs [p]settickets max_open_tickets_by_member main 3

📖 Konwencje

  • [p] = Twój prefix bota. Główna grupa to [p]ticket z aliasem [p]tickets.
  • <profile> = nazwa profilu konfiguracji. Domyślny profil to main.
  • Jeśli pominięto argument [ticket], komenda działa na ticketcie, w którym aktualnie się znajdujesz.
  • Domyślne wartości ustawień zaznaczono jako domyślnie: ….
  • Legendy uprawnień: wszyscy support admin / zarządzanie serwerem właściciel bota

➕ Tworzenie ticketów

Tworzenie ticketu dla siebie lub dla innego użytkownika.

KomendaDostępOpis
[p]ticket create [profile] [reason]alias: + wszyscy Tworzy ticket dla siebie. profile (domyślnie main) wybiera profil konfiguracji, reason to opcjonalny powód utworzenia.
[p]ticket createfor <member> [profile] [reason] admin Tworzy ticket w imieniu wskazanego użytkownika (np. gdy ma on zablokowany dostęp).

Przykłady:

[p]ticket create [p]ticket create Wsparcie techniczne — bot się zawiesza [p]ticket + [p]ticket createfor @Janek Reklamacja zamówienia #123

⚙️ Akcje na tickecie

Zmiana statusu, przypisanie, blokowanie i odwołania.

KomendaDostępOpis
[p]ticket close [ticket] support Zamyka ticket. Jeśli włączony jest modal powodu, zostanie o niego zapytany właściciel.
[p]ticket reopen [ticket]alias: open support Ponownie otwiera zamknięty ticket.
[p]ticket claim [ticket] support Przypisuje ticket do siebie (claim).
[p]ticket unclaim [ticket] support Zdejmuje przypisanie z ticketa.
[p]ticket lock [ticket] support Blokuje kanał — nikt nie może pisać w tickecie.
[p]ticket unlock [ticket] support Odblokowuje kanał po zablokowaniu.
[p]ticket approveappeal [ticket] support Zatwierdza odwołanie — użytkownik zostaje odbanowany w docelowym serwerze.
[p]ticket delete [ticket] support Usuwa kanał ticketa. Wcześniej może zostać wygenerowany transkrypt.

Przykłady (bez argumentu działają na tickecie, w którym jesteś):

[p]ticket close [p]ticket reopen [p]ticket claim [p]ticket unclaim [p]ticket lock [p]ticket unlock [p]ticket close #ticket-12-Jakub

🔽 Przyciski vs Dropdown

Obie formy doklejane są do wiadomości i tworzą tickety — różnią się wyglądem i przeznaczeniem.

🔽 Dropdown (menu rozwijane)

Menu wyboru (discord.ui.Select) — lista opcji rozwijana po kliknięciu. Każda opcja odpowiada jednemu profilowi ticketów (np. „Pomoc", „Reklamacja", „Zwrot"). Wybór opcji tworzy ticket z tym profilem, a etykieta opcji staje się kategorią ticketa.

  • Do czego służy: gdy masz dużo kategorii ticketów — zamiast wielu przycisków zajmujących miejsce dajesz jedno menu z nawet 25 opcjami.
  • Kiedy użyć: przy wielu kategoriach (oszczędza miejsce na wiadomości); przy 2–3 głównych opcjach lepsze są przyciski, które są od razu widoczne.
  • Można łączyć: kilka przycisków + jeden dropdown na tej samej wiadomości.

Przykłady:

[p]settickets adddropdownoption #wyslij-tu 🛠️ Pomoc techniczna Naprawa problemów z botem [p]settickets adddropdownoption #wyslij-tu 💰 Reklamacja Zwrot za zakup [p]settickets adddropdownoption #wyslij-tu 🕵️ Odwołanie od bana [p]settickets adddropdownoption #wyslij-tu reklamacje main 💸 Zwrot

🔘 Przyciski

Każdy przycisk tworzy ticket z przypisanym profilem. Do 20 przycisków na wiadomość, z kolorami:

NumerKolor
1primary (niebieski)
2secondary (szary) — domyślny
3success (zielony)
4danger (czerwony)

Przykłady:

[p]settickets addbutton #wyslij-tu 🛠️ 3 Pomoc [p]settickets addbutton #wyslij-tu 💰 4 Reklamacja [p]settickets addbutton #wyslij-tu reklamacje main 📩 1 Otwórz ticket [p]settickets addbutton #wyslij-tu 2 Otwórz ticket

Wskazówka: opcje między addbutton/adddropdownoption to kolejno: <wiadomość> (kliknij prawym / użyj [p]message do linku), [profile] (domyślnie main), [emoji] i [style]. Wszystkie elementy usuwa [p]settickets clearmessage <wiadomość>.

🧰 Setup, przyciski i odwołania

KomendaDostępOpis
[p]settickets setup admin Interaktywny przewodnik konfiguracji krok po kroku.
[p]settickets addbutton <message> [profile] [emoji] [style] <label> admin Dodaje przycisk tworzenia ticketu do wiadomości. Style: 1 = primary, 2 = secondary (domyślne), 3 = success, 4 = danger. Maks. 20 przycisków na wiadomość.
[p]settickets adddropdownoption <message> [profile] [emoji] <label> [description] admin Dodaje opcję do menu wyboru (dropdown) na wiadomości. Maks. 25 opcji.
[p]settickets clearmessage <message> admin Usuwa wszystkie przyciski/opcje dodane przez system z wiadomości.
[p]settickets configureappeals <profile> <guild_id> <invite> [moderator_role] [category_open] [category_closed] [logs_channel] [button_channel] admin Konfiguruje system odwołań od banów. Docelowy serwer jest podawany przez guild_id + zaproszenie; wymaga tam uprawnień Manage Server i Ban Members. Można też wskazać kanał, na którym bot automatycznie postawi wiadomość z przyciskiem odwołania.
[p]settickets getdebugloopstatus owner Ukryta komenda diagnostyczna — status pętli sprawdzania ticketów.
